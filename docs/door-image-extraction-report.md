1. **GameRant CDN:** `static0.gamerantimages.com` - High-quality JPG screenshots
2. **DualShockers CDN:** `static0.dualshockersimages.com` - High-quality JPG screenshots

### Recommended Download Strategy

For each key, download:
1. **Locked Door Image** - Shows what the door looks like
2. **Map Location Image** - Shows where the door is on the map
3. **Interior/Loot Room** - Shows what's inside (if available)

### Image Naming Convention Suggestion

When saving locally, use this format:
```
{key-name}_{type}.{ext}

Examples:
blue_gate_confiscation_door.jpg
blue_gate_confiscation_map.jpg
blue_gate_confiscation_interior.jpg
```

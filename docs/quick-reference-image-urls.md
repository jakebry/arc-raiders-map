## Download Tips

1. **Use curl with -L flag** to follow redirects:
   ```bash
   curl -L -o filename.jpg "URL"
   ```

2. **Use wget** as alternative:
   ```bash
   wget -O filename.jpg "URL"
   ```

3. **Batch download** using the provided script:
   ```bash
   ./download_door_images.sh
   ```

4. **File formats:**
   - GameRant/DualShockers: `.jpg` (high quality, larger files)
   - Eldorado.gg: `.webp` (modern format, smaller files)

# Keycard Icon Image Mapping

This document maps each key in Arc Raiders to its corresponding icon image file.

## Dam Battlegrounds
All Dam keys use the same image: `dam_battlegrounds_key.png`
- Dam Surveillance Key
- Dam Staff Room Key
- Dam Testing Annex Key
- Dam Control Tower Key

## Spaceport
All Spaceport keys use the same image: `spaceport_key.png`
- Spaceport Trench Tower Key
- Spaceport Warehouse Key
- Spaceport Control Tower Key (Spaceport Ground Control Key)
- Spaceport Container Storage Key

**Note:** Spaceport Outskirts Bunker Key was not found on the Arc Raiders wiki.

## Buried City
All Buried City keys use the same image: `buried_city_key.png`
- Buried City Residential Master Key
- Buried City JKV Employee Card (JKV Employee Access Card)
- Buried City Hospital Key
- Buried City Town Hall Key

## Blue Gate
Blue Gate keys use two variants:

### Variant 1: `blue_gate_key_variant_1.png`
- Blue Gate Village Key
- Blue Gate Cellar Key

### Variant 2: `blue_gate_key_variant_2.png`
- Blue Gate Communication Tower Key
- Blue Gate Confiscation Room Key

### Unique: `patrol_car_key.png`
- Blue Gate Patrol Car Key (Patrol Car Key)

## Stella Montis
All Stella Montis keys use the same image: `stella_montis_key.png`
- Stella Montis Assembly Admin Key
- Stella Montis Medical Storage Key
- Stella Montis Archives Key
- Stella Montis Security Checkpoint Key

## Special
- Raider Hatch Key: `raider_hatch_key.png` (unique image)

## Image Sources
All images were downloaded from the Arc Raiders Wiki:
- Wiki Category Page: https://arcraiders.wiki/wiki/Category:Key
- Individual key pages contain the full-resolution images
- Images are PNG format with transparent backgrounds where applicable

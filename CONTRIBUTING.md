# Contributing to Arc Raiders Keycard Map

Thanks for your interest in contributing! 🎉

## How to Help

### 🐛 Report a Bug
- Open an [issue](https://github.com/jakebry/arc-raiders-map/issues) with steps to reproduce

### 📍 Fix or Add Marker Locations
1. Fork the repo and clone locally
2. Edit `js/data.js` — keycard/door entries are coordinate arrays `[y, x]` in pixel space
3. Test with `npx vite` (opens at http://localhost:5173)
4. Submit a PR with a description of what changed

### 💡 Request a Feature
- Open an issue with the **Feature Request** template

## Guidelines
- Keep it simple — this is vanilla JS, no frameworks
- Test on both desktop and mobile before submitting
- One feature per PR

## Code of Conduct
Be respectful. We're all here because we love the game.
